# SPA Project

Replication package for the Satisfiability Problems and Applications Exam (Core Module at GSSI).

## Theano
_Theano_ is a tool that checks the _completeness_ and _consistency_ of Requirements Tables (RT).
It also includes _composition_ and _substitutability_ operations to verify the safety of
OTA updates.

In this project we use only the _substitutability_ check.

## Requirements

- [z3](https://github.com/Z3Prover/z3)
- [cvc5](https://cvc5.github.io/docs/cvc5-1.0.0/installation/installation.html)

## Install

- _Theano_ requires [Python3](https://www.python.org/downloads/) and [Java](https://www.java.com/en/download/manual.jsp).

- Install the required Python libraries:

On Windows:

```terminal
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

On macOS/Linux:

```terminal
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Replicate experiments
 
To replicate the experiments for the project, execute the bash file:

```terminal
bash run.sh
```

The script execute 20 OTA updates for 50 times per each strategy (i.e., double-check and single-check with _Theano_, z3 and cvc5 via command line with the SMT-LIB files generated by _Theano_).

Each OTA update is an RT from the `LM_Challenges` folder in this repository.

To keep the generated files in `LM_Challenges` folder add the -k option. To modify the number of iterations, specify it with the -i option. For example:

```terminal
bash run.sh -k -i 100
```

## Results
The results are saved in the `results` folder.
To visualize the boxplots, open [MATLAB Simulink](https://www.mathworks.com/help/install/ug/install-products-with-internet-connection.html) and run

```matlab
benchmark
```

 It will show the boxplots and save them as .png images in the `results` folder.
